# Dictionnaire des données DPPH

Ce fichier décrit les variables du jeu de données fictif `data_example/exemple_dpph.csv`.

Les valeurs sont entièrement fictives et utilisées uniquement à des fins pédagogiques. Elles ne représentent pas des résultats expérimentaux de la thèse.

| Variable | Description | Type / unité |
|---|---|---|
| sample_id | Identifiant de l'échantillon fictif | Texte |
| concentration_ug_ml | Concentration testée | Numérique, µg/mL |
| inhibition_pct | Pourcentage d'inhibition DPPH | Numérique, % |

Les données réelles de la thèse restent confidentielles jusqu'à autorisation de diffusion.
